# مصفوفة أدلة التحقق من مؤشرات KPI

- الفرع: `audit/kpi-evidence-matrix-2026-11`
- نقطة الأساس: `d1853c8c8596ee734c32f25d14603c6d1b8cf355`
- النطاق: مراجعة ثابتة لسجل `KPI_REGISTER.md` واختبارات المستودع المشار إليها فيه، دون تغيير منطق الحساب أو ملفات البيانات.
- الغرض: التمييز بين وجود مرجع اختبار وبين وجود دليل فعلي على صحة قيمة المؤشر.
- حارس التوثيق: `tests/test_kpi_coverage_matrix.py` يتحقق من وجود 48 صفًا، وتسلسل المعرّفات، وصحة مراجع الاختبارات، وتوزيع التصنيفات؛ ولا يختبر المعادلات نفسها.

## منهج التصنيف

| التصنيف | المعنى |
|---|---|
| A — تحقق حسابي مباشر | الاختبار يعيد حساب القيمة/المعادلة أو يثبت مطابقة رقمية مباشرة مع مصدر مستقل أو إجمالي متوقع. |
| B — تحقق مصدر/تكامل جزئي | يثبت تطابقًا مع مصدر أو فترة أو عرض، لكنه لا يغطي كل أبعاد المؤشر أو لا يعيد حسابه بصورة مستقلة. |
| C — تحقق عام فقط | الاختبار عام للقاموس/الكتالوج أو يثبت وجود بيانات/عرضًا، ولا يثبت قيمة هذا المؤشر تحديدًا. |
| M — ربط غير صحيح/غير كافٍ | الاختبار المذكور لا يثبت المؤشر المحدد أو يبدو أنه مرتبط بمؤشر آخر. |
| N — غير قابل للتحقق حاليًا | المؤشر لا يملك بيانات مصدر لازمة، ولذلك لا توجد قيمة فعلية يمكن مطابقتها. |

**قاعدة مهمة:** وجود اختبار يذكر اسم جدول التصدير أو اسم المؤشر ليس إثباتًا حسابيًا. كما أن نجاح الاختبار لا يثبت تلقائيًا صحة كل صف في جدول التصدير.

## الملخص

| التصنيف | عدد المؤشرات | الدلالة |
|---|---:|---|
| A — تحقق حسابي مباشر | 30 | توجد أدلة حسابية أو مطابقة رقمية محددة، مع بقاء حدود النطاق الموضحة أدناه. |
| B — تحقق مصدر/تكامل جزئي | 7 | دليل جزئي، ويحتاج استكمالًا قبل اعتماد تغطية كاملة. |
| C — تحقق عام فقط | 8 | لا يُعد تحققًا حسابيًا للمؤشر. |

| N — غير قابل للتحقق حاليًا | 2 | بيانات الموازنة/التدفق النقدي المتوقع غير متاحة. |
| **الإجمالي** | **48** | التصنيف لا يغير حالة اعتماد المؤشر المالية في السجل الأصلي. |

## أولويات المعالجة

### P0 — قبل اعتبار تغطية KPI مكتملة
1. K002: إضافة اختبار مستقل لمجمل الربح، وتصحيح ربطه في سجل KPI.
2. K004 وK007 وK008 وK009 وK012: اختبارات حسابية مستقلة للقيم الأساسية.
3. K014 وK015: إبقاء الحالة «غير متاح» حتى ورود مصادر فعلية معتمدة.
4. K024 وK026: اختبار معادلتي DSO وDPO من مصادرهما، لا الاكتفاء باختبار نطاق.
5. K047: اختبار حساب عمولة 2.5% لكل صنف وربطها بسعر البيع.
6. K045 وK046: إعادة حساب تكلفة العبوة وهامش الوصفة من عناصر المصدر.

### P1 — تقوية المطابقة والتصدير
1. إضافة اختبارات آلية تقارن صفوف جداول التصدير مع نواتج الدوال لكل مؤشر، لا مجرد وجود الجدول.
2. اختبار تغطية كل شهر/مندوب/صنف متاح، مع حالات البيانات الناقصة والصفرية.
3. توحيد تعريف DIO التشغيلي وDIO القوائم أو توضيح اختلافهما في سجل المؤشرات.
4. إضافة حالات اختبار للأصناف غير المربوطة، والكميات الصفرية، والمقامات الصفرية، والبيانات المكررة.

## ضوابط سلامة البيانات المطلوبة بعد هذه المصفوفة

- عدد السجلات قبل وبعد كل تحويل، مع تفسير أي فرق.
- مجموع المبيعات والكميات والمرتجعات والتحصيلات قبل وبعد التحويل.
- منع فقد السجلات أو مضاعفتها بسبب joins أو إزالة التكرار.
- مطابقة أرصدة العملاء والموردين والمخزون مع ملفات المصدر وتاريخ اللقطة.
- إعادة بناء ملفات التصدير من المصادر ومقارنة الناتج بالمخرجات المعتمدة.
- اختبار اتساق الفترة الزمنية، وحدود الفلاتر، وتاريخ آخر تحديث.
- حفظ بصمات SHA-256 للمدخلات والمخرجات في سجل بناء قابل للمراجعة.

## حدود المراجعة

هذه المصفوفة مراجعة ساكنة لأجسام الاختبارات وتعريفات المؤشرات والربط الظاهر في سجل KPI. لم تُشغّل الاختبارات محليًا ولم تُعد حساب كل القيم من ملفات البيانات الخام في هذه الخطوة. التصنيفات A/B تعني أن الاختبار الموجود يقدم دليلًا من النوع الموضح، لا أن جميع فترات المؤشر وكل صفوف التصدير قد تم تدقيقها. لا تُغيّر هذه المصفوفة حالة اعتماد أي مؤشر ولا تستبدل موافقة الإدارة المالية.
